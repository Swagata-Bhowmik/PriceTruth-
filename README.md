## 📁 Files

- `index.html` - Landing page with beautiful hero and feature showcase
- `dashboard.html` - Interactive dashboard with all 5 core features

## 🎨 Features

1. **True Discount Checker** - ML verification with SHAP explainability
2. **Live Pack Lookup** - Real-time product data via Open Food Facts API
3. **Unit Price Comparator** - Best value analysis across pack sizes
4. **Buy Timing Signal** - AI-predicted optimal purchase timing
5. **Shrinkflation Timeline** - Track pack-size reductions over time
